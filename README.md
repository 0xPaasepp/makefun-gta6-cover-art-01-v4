Velvet Heat is an offline cover studio that turns a photo and a caption into GTA 6-style cover art: the iconic multi-panel poster look with a Vice City neon-sunset grade. Dual engine — face-aware ink (78% posterize + halftone, faces stay readable) and five photographic grades — six templates, per-panel crop, rotate and zoom, undo/redo, and one-click export to 1080x1080, 1080x1350 and 1920x1080 PNGs. Everything runs offline in the browser; photos never leave the machine.

## Run it

```sh
node serve.ts
```
